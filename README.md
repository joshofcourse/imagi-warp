# imagi-warp

Envelope-warp tool for the iMAGi wordmark (Figma frame 213). Single `index.html`, no build step — open it in a browser.

- **Corners** — offset each corner in x/y (sliders, typed values, or drag the handles)
- **Bulge** — bow the top and/or bottom edge; Link moves both together
- **Slots** — save up to 6 poses and loop between them with a custom cubic-bezier ease
- **Export SVG** — download the current warped wordmark
